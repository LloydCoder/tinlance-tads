# Buying Windows

X6 represents a bounded period in which evidence-backed account conditions may make an opportunity actionable.

## Important semantic boundary

A buying window is not a claim that an account intends to purchase. It is a lifecycle hypothesis derived from evidence, signals and state changes.

## Lifecycle

EMERGING -> ACTIVE -> COOLING -> DORMANT

Any state may transition to INVALIDATED.

Every window has explicit opening and expiry timestamps, evidence IDs and trigger IDs.

## Boundary

X6 does not send outreach, infer private intent, or mutate source evidence. FadeReach remains responsible for engagement execution; SDEA remains responsible for acquisition strategy.
