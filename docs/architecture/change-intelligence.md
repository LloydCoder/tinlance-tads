# Change Intelligence

X4 detects material transitions in account state over the existing temporal and account layers.

## Semantics

A first observed account state is an emergence event. Subsequent differences are deterministic material changes; complete removal of previously present fields is represented as disappearance rather than as an invented opposite fact.

Every state and change requires evidence and timezone-aware timestamps.

## Boundary

X4 does not infer purchase intent, create outreach, or rewrite historical account state. Acceleration, deceleration and reversal remain higher-order interpretations that require a richer temporal corpus; the current primitive intentionally fails conservative rather than inventing those labels.

## Provenance

A StateChange points to the current evidence supporting the new state and retains the previous observation timestamp. This preserves reconstructability and is compatible with provenance models that represent entities, activities and derivations.
