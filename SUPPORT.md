# Support

TADS is a proprietary Tinlance engineering repository. Support is intended for authorized users, contributors, and integration partners.

## Where to ask

| Need | Channel |
|---|---|
| Security vulnerability | [SECURITY.md](SECURITY.md) — private report only |
| Confirmed bug | GitHub issue using the bug form |
| Feature or architecture proposal | GitHub issue using the feature form |
| General project question | GitHub issue with enough context to reproduce or answer it |
| Commercial/integration enquiry | hello@tinlance.com |

Before opening an issue, search existing issues and documentation.

## What to include

For bugs, include:

- expected behavior;
- actual behavior;
- exact command or API operation;
- Python and PostgreSQL versions;
- relevant logs with secrets removed;
- a minimal reproduction where possible.

Do not include credentials, customer records, private provider data, or other confidential material.

## Response expectations

Issue response time depends on severity and maintainer availability. Security reports follow the targets in [SECURITY.md](SECURITY.md).
